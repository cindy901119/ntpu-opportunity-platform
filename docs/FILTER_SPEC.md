# FILTER_SPEC

## v0.8-B preferences UI 修正

- 「我的資格」欄位維持：學校、主修系所、年級、雙主修、輔系。
- 雙主修與輔系在前台以開關呈現；開啟後才顯示系所選單，避免預設佔用過多空間。
- v0.8-D 起目前只支援「國立臺北大學」正式清洗版系所 mapping；北聯大其他學校待整理正式清單後再擴充。
- 主修系所需使用正式完整名稱，例如「金融與合作經營學系」，不要使用「金融系」簡稱。
- 主修系所、雙主修、輔系的系所選擇使用 searchable combobox；搜尋可比對正式名稱與 aliases，但前台顯示結果一律使用正式完整名稱。
- 學院由學校＋主修系所 mapping 推導，不顯示在前台，也不提供使用者選擇。
- 就讀階段由年級推導，不新增輸入欄位。
- 主題領域維持複選；常用項目先顯示，低頻項目放在「展開更多」。
- 獎勵形式限定為：獎金、獎品、證書、補助、無明確獎勵、未寫清楚。
- 最高獎金使用範圍拉桿與「不限」checkbox；v0.8-C 起拉桿刻度暫定為 1,000 元。
- 「交件形式」取代「文件形式」。
- 「其他條件」取代「重視條件」，第一版保留北大限定、北聯大限定、可個人參加、可組隊、線上繳交。

## 第一版核心 filter

1. 我的資格
2. 機會類型
3. 主題領域
4. 截止時間
5. 獎勵形式
6. 最高獎金

## Filter 1：我的資格

欄位順序：

1. 學校
2. 主修系所
3. 年級
4. 雙主修
5. 輔系

規則：

- 學校 → 主修系所 → 年級 → 雙主修／輔系。
- 學院由學校＋主修系所推導。
- 就讀階段由年級推導。
- 大一～大四推導為大學部。
- 碩一～碩二推導為碩士班。
- 碩士班可以隱藏雙主修／輔系欄位，或讓它們不是必填。
- 需組隊、團隊人數、可跨校組隊屬於報名形式／組隊條件，不屬於「我的資格」。

## Filter 2：機會類型

第一版：

1. 比賽
2. 獎學金
3. 補助／計畫
4. 其他

不要獨立新增「徵件」。徵件可作為比賽或補助／計畫的補充標籤，不作為第一版主要機會類型。

## Filter 3：主題領域

資料結構：複選。

預設顯示：

1. 商業／企劃
2. 創業／新創
3. 科技／程式
4. 法政／公共議題
5. 社會／永續
6. 不限／不適用

展開更多：

1. 人文／寫作
2. 語言／國際
3. 設計／創作
4. 其他

規則：

- 主題領域可以複選，不要做成單選。
- 獎學金不強迫歸類主題，很多獎學金應標「不限／不適用」。
- 影片、音樂、歌唱、攝影等不獨立放在第一排主題領域；低頻創作類先進「設計／創作」或「其他」。

## Filter 4：截止時間

前台 filter：

1. 三天內
2. 一週內
3. 一個月內
4. 一個月以上
5. 截止日未明

規則：

- 前台列表預設只顯示尚未截止的機會。
- 已截止資料可保留，但不進第一版主列表。
- 「尚未截止」不放進截止時間 filter。

## Filter 5：獎勵形式

資料結構：複選。此欄用來描述回報形式，例如獎金、獎學金、補助、實體資源、曝光、證書等；v0.2 前需再定正式 label。

## Filter 6：最高獎金

用最高可得金額判斷，不要把總獎金池當成最高獎金。

## 目前落地狀態

- v0.1 目前已落地「我的資格」與「機會類型／偏好」的基本 demo。
- v0.2 已開始落地「主題領域、截止時間、獎勵形式、最高獎金」到偏好頁與列表篩選。
- v0.2 仍使用 mock data 與 localStorage，不接後端。
