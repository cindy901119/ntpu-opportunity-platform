# UI_RULES

- 使用者端不顯示 internalScore。
- 使用者端不顯示推薦分數。
- 使用者端不顯示加權數字。
- 推薦卡片要顯示：
  - 推薦標籤
  - 為什麼推薦你？
  - 資格符合
  - 偏好交集
  - 警告或需確認事項
- 活動詳情頁按鈕文字用「查看官方簡章」，不要寫成「立即報名」。
- 詳情頁要保留 specialNotes「特別注意」區塊。
- 卡片格式要固定，手機版不要讓卡片資訊無限制堆長。
- 卡片推薦標籤只保留一個，不要在右上角重複顯示資格狀態。
- 推薦標籤前台文字統一為「很適合你」「可以考慮」「再確認」。
- 列表卡片只保留站內「查看詳情」與「收藏」；「查看官方簡章」放在詳情頁作為主要 CTA。
- 卡片最多顯示 3 個 tag，詳細分類放到詳情頁。
- 卡片資訊列需壓縮：截止與獎金同一行；資格最多兩行；交件最多兩行；簡介最多兩行。
- 截止與獎金顏色要有資訊意義，依剩餘天數與金額級距動態呈現。
- 詳情頁底部主要 CTA 使用「查看官方簡章」，提醒使用者以官方規則為準。
- 「與你的設定相符」展開區不要寫成推薦演算法說明；資格符合最多 2～3 項，偏好交集最多 5 個短詞。
- 列表與收藏頁桌機版可使用兩欄；偏好頁維持單欄但可加寬。
